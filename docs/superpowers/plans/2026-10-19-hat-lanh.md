# Hạt Lành Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, running locally, a vegetarian macrobiotic food shop: customer portal, admin site and one shared API/database, with 10 seeded products.

**Architecture:** npm-workspaces monorepo. One NestJS API (feature modules: controller → service → Prisma) over PostgreSQL in Docker; a Next.js portal and a React+Vite admin that both call the API with bearer JWTs; a `shared` package holds validators and constants used by all three. Telegram, real OAuth and VietQR are plug-in seams (console/dev stubs now).

**Tech Stack:** TypeScript, Node 22, NestJS, Prisma, PostgreSQL 16 (Docker), Jest (api), Vitest (shared, portal, admin), Zod, Next.js (App Router), React + Vite, sanitize-html.

**Spec:** `docs/superpowers/specs/2026-10-19-hat-lanh-design.md` (read it; this plan implements it section by section and uses its "Quyết định của Claude" items as decided).

## Global Constraints

- Ports: api 3000, portal 3001, admin 3002. Workspaces: `apps/api`, `apps/portal`, `apps/admin`, `packages/shared`. Package scope `@hatlanh/*`.
- UI language Vietnamese; money is integer VND (`priceVnd`, `totalVnd`); times use `Asia/Ho_Chi_Minh` for reports.
- Phone rule: Vietnamese mobile, 10 digits, normalized form `0` + `3|5|7|8|9` + 8 digits (e.g. `0912345678`). Address is 2-level: Tỉnh/Thành + Phường/Xã + detail text, all required.
- Checkout page text must include: "Phí vận chuyển sẽ được báo khi xác nhận đơn". No online payment, no shipping fee computation, no email/SMS sent to customers.
- Notifications go through `Notifier` and currently `console.log` with prefix `[NOTIFY]`.
- `payments` module is an empty seam with a `TODO(VietQR)` comment containing the four notes from spec §8.3.
- Content must never claim to cure/treat disease: seed text and UI copy must not contain "chữa", "trị bệnh", "khỏi bệnh". Origin field in seed data is exactly `[Điền vùng trồng / nhà cung cấp]`.
- Secrets only in `.env` (provide `.env.example`). Admin seed account `admin@hatlanh.local`, password from `ADMIN_PASSWORD` (default `ChangeMe123!`).
- Style B tokens: `--green-500:#A8C3A0; --green-100:#EAF1E6; --honey-400:#E8C27A; --ink-800:#2E3B33; --bg:#FAFAF7`; sans-serif, rounded corners, mobile-first.
- Project is not yet a git repo: Task 1 runs `git init`. End commit messages with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Two customers order the last unit at once: exactly one succeeds, the other gets 409 `OUT_OF_STOCK`, stock never goes negative (Task 7).
2. Phone typed as `0912 345 678`, `+84912345678`, `84912345678`, `091-234-5678` is accepted and normalized to `0912345678`; `0123456789`, `091234567`, letters are rejected (Task 2).
3. Order lines with quantity 0, negative, fractional, > stock, an unknown/inactive variant, an empty list, or the same variant twice (merged) behave sanely (Task 7).
4. Registering `A@X.com` after `a@x.com`, or `+84912345678` after `0912345678`, is rejected as duplicate (Task 5).
5. Moderation catches `TRỊ BỆNH`, `tri benh`, `chua khoi`, phone numbers and links in comments/reviews; blog HTML with `<script>` or `onerror=` is sanitized (Tasks 9, 10).
6. A return quantity larger than what was bought minus earlier non-rejected returns, or on a non-completed order, is rejected (Task 8).
