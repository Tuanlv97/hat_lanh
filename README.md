# Hạt Lành

Cửa hàng thực phẩm chay: NestJS API + Next.js portal + React/Vite admin + shared package, trên PostgreSQL.

## Ports
- API: 3000
- Portal: 3001
- Admin: 3002
- Postgres: 5432 (databases `hat_lanh`, `hat_lanh_test`)

## Quick start
```
cp .env.example .env
npm install
npm run db:up
npm run dev
```
